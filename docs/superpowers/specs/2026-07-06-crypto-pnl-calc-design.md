## 目的

- **学習目的**: Web開発 (Astro + React 島) と AI バックエンド (Cloudflare Pages Functions で Claude API をキー保護して呼ぶ) の習得。
- **収益導線**: 既存ブログ [[project-affiliate-blog]] (crypto-bot-blog) の「損益ツール」ASP 枠へのリンク先。免責内でクリプタクト等の専用ツールへ誘導。

## アーキテクチャ

- **Astro プロジェクト**。トップページ (`index.astro`) に計算機を1枚。
- 計算機本体は **React 島** (`client:load`)。損益・税の計算は**すべてクライアント側**で即時実行 (サーバー不要・API課金ゼロ)。
- **AI解説のみ** Cloudflare Pages Function (`functions/explain.ts`) 経由で Claude API を呼ぶ。`ANTHROPIC_API_KEY` は Cloudflare 環境変数 (Secret) に格納し、ブラウザには一切出さない。
- モデル: `claude-sonnet-5`。

## 計算ロジック (純粋関数、UIから独立)

### 入力
- 買値 (円/単位)、売値 (円/単位)、数量
- 売買手数料: パーセント指定または定額指定 (どちらか)
- その年の他の所得 (給与所得等、任意・円)

### 出力 (`src/lib/calc.ts`)
- **実現損益** = (売値 − 買値) × 数量 − 手数料合計
- **損益率** (%) = 実現損益 / (買値 × 数量) × 100
- 手数料は買い・売り両方にかかる想定。パーセントなら各約定代金に対して計算。

### 税金概算 (`src/lib/tax.ts`)
- 日本の暗号資産は**雑所得・総合課税**。他の所得に損益 (プラス時のみ) を上乗せし、累進で「増える税額」を概算。
- **所得税の累進テーブル** (課税所得ベース、2026年時点の一般的な区分):
  | 課税所得 | 税率 | 控除額 |
  |---|---|---|
  | 〜195万 | 5% | 0 |
  | 〜330万 | 10% | 97,500 |
  | 〜695万 | 20% | 427,500 |
  | 〜900万 | 23% | 636,000 |
  | 〜1,800万 | 33% | 1,536,000 |
  | 〜4,000万 | 40% | 2,796,000 |
  | 4,000万超 | 45% | 4,796,000 |
- **住民税**: 一律 10% として概算に加算。
- 概算税額 = (他所得+損益 の税額) − (他所得のみ の税額)。他所得が空欄なら「損益のみを課税所得と仮定した目安」を表示し、その旨を注記。
- 復興特別所得税 (2.1%) は概算のため**含めない** (注記する)。損失は税額ゼロ (損益通算・繰越は雑所得では不可の旨を注記)。

### 免責 (必須)
「本ツールの税額は概算であり、税務上の助言ではありません。正確な損益計算・確定申告には専用ツール (クリプタクト等) や税理士をご利用ください。」を計算結果近くとページ下部に明記。

## AI解説機能

- 「AIに解説してもらう」ボタン → 入力値と計算結果 (JSON) を `POST /explain` に送信。
- Function 内で Claude を呼び、**日本語で平易に数行**「この損益・年収なら税面でこう考える/こういう点に注意」を返す。免責を必ず添えるようプロンプトで指示。
- **セキュリティ/堅牢性**:
  - APIキーは Cloudflare Secret のみ。リクエストボディは数値と計算結果に限定 (自由入力プロンプトは受けない = プロンプトインジェクション面を絞る)。
  - キー未設定・API失敗・タイムアウト時は 200 以外を返し、フロントは「解説は今使えません。計算結果はそのまま有効です」と表示 (計算機は常に動く)。
  - 簡易レート制限 (同一IPの短時間連打を軽く抑制、KV等が要る場合は最小実装 or 省略可)。

## エラー処理

- 入力バリデーション: 非数値・負値・空欄 → 画面に日本語エラー、可能な範囲で計算は継続。
- 数量0や買値0による0除算 → 損益率は「—」表示。
- AI関数の各種失敗 → フロントでフォールバック表示、計算結果は保持。

## テスト方針

- `calc.ts`: 利益/損失/手数料パーセント/手数料定額/0除算ガードを単体テスト。
- `tax.ts`: 各税率区分の**境界値** (195万/330万/695万/900万/1800万/4000万) と、他所得あり/なし、損失時ゼロを固定テスト。
- `Calculator.tsx`: 主要な入力→表示の結合を軽くテスト (任意、コンポーネントテスト)。
- AI関数はモックで正常・失敗経路を確認。

## デプロイ

- GitHub → Cloudflare Pages 自動デプロイ (既存ブログと同じ運用)。
- Cloudflare 側で `ANTHROPIC_API_KEY` を Secret 登録。ビルドコマンド `astro build`、Functions は `functions/` 自動認識。
